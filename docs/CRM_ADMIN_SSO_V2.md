# CRM admin SSO v2
Active signed CRM session and fresh dashboard password reconfirmation are required. The CRM issues an HMAC-SHA256 v2 ticket with issuer/audience, a random 128-bit nonce and 60-second expiry. No network/IP allowlist is used. Cloud validates the signature, exact HTTPS Origin, version, timestamps and single-use nonce, then regenerates its session and uses normal session lifetime. v1 tickets are rejected.
Set `PUBLIC_BASE_URL=https://crm.ivrphone.org` and `HOSTEL_SSO_SHARED_SECRET` (32+ strong random characters) in the CRM; set the SAME secret and `HOSTEL_SSO_CRM_ORIGIN=https://crm.ivrphone.org` in Cloud. Deprecated IP/proxy variables are ignored. Deploy BOTH current main branches before testing. On shared computers, log out of both services separately. Cloud direct login TOTP remains unchanged.
